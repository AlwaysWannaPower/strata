{# Комментарий: два способа начать работу — оба ведут на уже существующие маршруты (`POST /w/{slug}/entities` и `POST /w/{slug}/scan`), поэтому в веб-слое не появляется новых состояний: пользователь либо называет папку одной таблицы, либо сканирует корень, где каждая прямая подпапка — сущность. Шаблон включается и в пустом состоянии, и внутри «Add more data» на хабе. #}
{# --- Вариант A: одна папка = одна сущность ----------------------------- #}

One folder = one entity

Name the table and point at its folder. All files there must belong to one table — the same columns in every file.

{# --- Вариант B: сканировать корень ------------------------------------- #}

Scan a root

Each direct subfolder becomes one entity. Nesting is not supported.

root/sales/*.csv · root/clients/*.csv

No allowed folder yet? Put your files in {{ files_area }} and scan that path. Scanning only proposes entities — nothing is saved until you confirm.
